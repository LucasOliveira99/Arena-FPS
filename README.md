# Arena FPS — Duelo 3D

Jogo 3D em primeira pessoa em uma arena contra um oponente controlado pela IA.

## Como jogar

1. Abra o `index.html` no navegador (ou use um servidor local).
2. Clique em **INICIAR DUELO**.
3. Use as **setas do teclado** para mover e girar.
4. Pressione **Espaço** para atirar.

## Controles

| Tecla | Ação |
|-------|------|
| ↑ | Avançar |
| ↓ | Recuar |
| ← | Girar à esquerda |
| → | Girar à direita |
| Espaço | Atirar |

## Servidor local (opcional)

```bash
npx serve .
```

Depois acesse `http://localhost:3000`.
